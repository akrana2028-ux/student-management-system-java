# Student Management System

A Java console-based Student Management System built using Object-Oriented Programming (OOP) and ArrayList.

## Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Student Statistics
- Grade Calculation
- Pass/Fail Result
- Input Validation
- Exception Handling

## Technologies Used

- Java
- OOP
- ArrayList
- Scanner
- Exception Handling

## Java Concepts Practiced

- Classes and Objects
- Constructors
- Encapsulation
- Methods
- Conditional Statements
- Loops
- ArrayList
- Exception Handling
